# 智慧冰箱与智能菜谱系统

基于 Spring Boot 3 + Vue 3 + MySQL 8 的课程设计项目，覆盖需求文档中的八大模块：账号与饮食偏好、冰箱分区温湿度、库存管理、保质期提醒、智能菜谱推荐、热量饮食管理、购物清单与数据统计。

## 技术栈

- 前端：Vue 3 + TypeScript + Vite + Element Plus + Vue Router + Pinia + Axios
- 后端：Spring Boot 3.5 + MyBatis-Plus + JWT + BCrypt
- 数据库：MySQL 8.0（utf8mb4）

## 快速开始

### 1. 初始化数据库

双击运行 `init-db.bat`，输入 MySQL root 密码；或在命令行执行：

```bash
mysql -u root -p < docs/schema.sql
```

脚本会创建 `smart_fridge` 数据库、全部数据表，并写入示例分类、重量估算表和 8 道示例菜谱。

### 2. 启动后端（IDEA）

1. 用 IntelliJ IDEA 打开 `backend` 目录（Maven 工程），等待依赖下载完成。
2. 若 MySQL 密码不是 `123456`，修改 `backend/src/main/resources/application.yml`
   中的 `password`，或通过环境变量 `DB_PASSWORD` 指定。
3. 运行主类 `com.smartfridge.SmartFridgeApplication`。
4. 后端默认地址：`http://localhost:8080/api`。

> 命令行方式：`cd backend && .\mvnw.cmd spring-boot:run`（首次会联网下载 Maven 与依赖）。

### 3. 启动前端

```bash
cd vite-project
npm install
npm run dev
```

浏览器访问 `http://localhost:5173`（已配置 `/api` 代理到后端 8080）。

### 4. 使用

注册一个新账号即可登录使用。建议体验顺序：

1. 个人设置：填写口味偏好、饮食目标与忌口；
2. 冰箱分区：新增冷藏/冷冻等分区，记录温湿度；
3. 库存管理：录入食材，查看系统给出的建议食用期限与低库存提醒；
4. 智能菜谱：查看可制作/缺少食材/可替代的推荐，支持按库存一键生成、用量调整、完成制作扣减库存；
5. 饮食记录、购物清单（可自动生成）、数据统计、提醒中心。

## 说明

- “AI”能力当前由规则引擎实现（库存覆盖匹配、忌口过滤、用量缩放、饮食评估），无需调用外部大模型；后续可平滑接入大模型 API 增强菜谱生成。
- 保质期仅为系统参考，不替代包装标注；温湿度异常时会提示用户自行检查食材状态。
- 生产环境请替换 `application.yml` 中的 JWT 密钥与数据库密码。
